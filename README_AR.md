# Field Shift — CALIPSO

تطبيق Streamlit بأربع صفحات، بتصميم أخضر وصورة حقول محفوظة داخل المشروع.

## التشغيل على اللابتوب
1. ثبّت Python 3.11 أو 3.12.
2. فك الضغط وافتح Terminal داخل مجلد field-shift.
3. نفّذ:

```bash
python -m venv .venv
```

Windows:
```powershell
.venv\Scripts\activate
```

macOS / Linux:
```bash
source .venv/bin/activate
```

ثم:
```bash
pip install -r requirements.txt
streamlit run app.py
```

## التعديلات الجديدة
- لغة إنجليزية بريطانية 🇬🇧 وعربية مصرية 🇪🇬، مع اتجاه من اليمين لليسار للعربية.
- دليل قابل للبحث فيه 250 مدخلًا للمحاصيل والأنواع الزراعية، بالأسماء العربية والإنجليزية.
- اختيار المحصول الحالي والمحصول المطلوب وفحص التكرار والعائلة النباتية والمحاصيل المعمرة.
- بدائل من مجموعة عمل فيها 30 محصولًا، مع توضيح طريقة ترتيبها.
- حذف خطوات تطوير المشروع من الواجهة، والإبقاء على الإرشاد الخاص باستخدام النتائج.
- عبارة «اتطوّر بواسطة فريق CALIPSO» بدون عدد أفراد.

## الصفحات
1. أرضك: البيانات واختيارات المحاصيل ودليل الـ250 مدخلًا.
2. المناخ: NASA POWER، ورسوم شهرية وتنزيل بيانات CSV.
3. المحصول الجاي: بدائل حسب العائلة النباتية ومسار «أنا عايز المحصول ده».
4. تقريري: بياناتك ونتيجة الفحص والمصادر وتنزيل JSON بلغتك.

## النشر الموصى به: Streamlit Community Cloud
1. أنشئ GitHub repository وارفع محتويات هذا المجلد، بما فيها assets و.streamlit.
2. افتح https://share.streamlit.io وسجل الدخول بحساب GitHub.
3. Create app → اختر المستودع والفرع → Main file path: app.py.
4. اختر Python 3.11 أو 3.12 ثم Deploy.
5. اختبر رابط التطبيق من متصفح آخر. بيانات جلسة المستخدم مؤقتة وليست قاعدة بيانات دائمة.

الوثائق: https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy

## لو محتاج رابط Vercel
هذا المشروع تطبيق Streamlit. لم يتم اختباره كنشر مباشر على Vercel، ولا يوجد إعداد Streamlit جاهز موثّق ضمن أطر Vercel المدعومة. دعم Python أو WebSocket وحده لا يثبت توافق إدارة جلسات Streamlit.

مجلد vercel-link يوفر تحويل رابط فقط؛ التطبيق نفسه يظل مستضافًا على Streamlit Cloud:
1. انشر التطبيق أولًا واحصل على رابط https://اسمك.streamlit.app.
2. افتح vercel-link/vercel.json واستبدل YOUR-APP باسم تطبيقك.
3. ارفع مجلد vercel-link إلى مشروع Vercel، أو اختره Root Directory في Import Git Repository.
4. اختر Other كإطار للمشروع ولا تضف أمر build.
5. Deploy. رابط Vercel سينقل الزائر إلى رابط Streamlit، وسيظهر رابط Streamlit في شريط العنوان.

الاستضافة الكاملة على Vercel تحتاج اختبار مسار نشر مخصص أو تحويل الواجهة لإطار مدعوم؛ ليست متحققة في هذه الحزمة.

## حالة التنفيذ والحدود
- اجتازت النسخة 6 مجموعات اختبارات: 250 مدخلًا فريدًا، قواعد الفرز، الصفحات الأربع باللغتين، حفظ المدخلات عند تبديل اللغة، اختيار بديل، وفشل اتصال NASA.
- تمت مراجعة الواجهة الإنجليزية والعربية ومقارنة المحاصيل في المتصفح.
- لا يوجد نشر عام جديد؛ الحزمة مخصصة للتشغيل المحلي ثم النشر على حسابكم.
- الدليل تحرير يدوي لأسماء المحاصيل والأنواع؛ ليس نسخة من قاعدة FAO ولا يحتوي 250 توصية معتمدة لمصر.
- بعض المدخلات أنواع تجارية لنفس النوع النباتي، مثل الكرنب الأحمر والكرنب، وليست 250 نوعًا نباتيًا مستقلًا.
- العائلات النباتية والقائمة تحتاج مراجعة زراعية مستقلة قبل الاستخدام الميداني.
- وصف annual في البيانات يعني محصولًا يدار موسميًا في هذا النموذج؛ قد تكون دورة حياة النبات الطبيعية أطول. الأشجار والمحاصيل المعمرة لا تدخل الترشيح الموسمي.
- الترشيح من 30 محصولًا يعتمد على اختلاف العائلة؛ أولوية صحة التربة تقدم البقوليات للاستكشاف فقط. لا يوجد ترتيب محسوب لتوفير المياه أو الملاءمة المحلية.
- إدخال المنطقة والتربة والشهر مسجل في التقرير، لكنه ليس فلتر ملاءمة زراعية حاليًا.
- سجل المناخ تاريخي وليس توقعات، ولا يدخل حاليًا في حساب الترشيحات.
- بيانات الجلسة مؤقتة ولا توجد قاعدة بيانات مستخدمين.

## الخطوات التالية للفريق
1. مراجعة واجهة المستخدم وتجربتها محليًا.
2. اختيار منطقة واحدة وعدد محدود من المحاصيل ومصدر محلي موثوق لمواعيد زراعتها.
3. جمع جدول المحاصيل والموسم والتربة والعائلة النباتية ومعاملات المحصول مع مصدر لكل قيمة.
4. مراجعة الدورات مع متخصص زراعي قبل إضافة ترشيحات أو أرقام توفير مياه.
5. ربط الحسابات الموثقة بالبيانات واختبار القيم المفقودة والمواسم غير المناسبة.
6. نشر التطبيق، ثم وضع الرابط وGitHub والمصادر في عرض المسابقة. راجعوا قواعد المنظم بخصوص ما يسمح بتجهيزه قبل الهاكاثون واذكروا المساعدة بالذكاء الاصطناعي.
